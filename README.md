# Daybook

Personal task + notes app (studies, projects, travel, personal) with a grungy halftone poster look.

- Static site: `index.html`, `sw.js` (offline shell), `manifest.webmanifest`, icons
- Data + login: Supabase (tables `items`, `pads`, row-level security per user)
- Hosting: Netlify, auto-deploys from `main`
